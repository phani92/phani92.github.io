# Portfolio Builder

A personal portfolio site written in plain HTML, CSS and vanilla JavaScript. There is no framework, build step or package manager. It is hosted on [GitHub Pages](https://pages.github.com/).

The blog posts are generated by an AI agent implemented in the [blogBot](https://github.com/phani92/blogBot) repository, which commits them here through GitHub Actions.

## Structure

- `index.html`: the homepage (nav, hero, services, projects, live blog strip, footer).
- `html/blogs.html`: the blog page (post list and reader).
- `css/`: `base.css` (tokens, nav, footer, shared by both pages), `home.css` (homepage), `blog.css` (blog page).
- `js/`: shared utilities `site.js`, `blog-utils.js`, `projects.js` (pure functions, unit tested) and page scripts `home.js` and `blogs.js`.
- `data/projects.json`: the projects shown on the homepage, in display order.
- `images/projects/`: compressed project images.
- `blogs/`: blog posts and `blogList.json`, written by blogBot. Do not edit by hand.
- `tests/`: unit tests for the utility scripts.

## Run locally

```
python -m http.server
```

Open `http://localhost:8000`. The pages load JSON with `fetch()`, so opening the HTML files straight from disk will not work.

## Test

```
node --test tests/*.test.js
```

## Add a project

1. Add an entry to `data/projects.json`. The array order is the display order, and the featured entry must stay first. Fields: `id`, `title`, `category` (`embedded` or `ai`), `tech`, `summary`, `repo`, and optionally `image`, `imageAlt`, `icon` (`chip`, `wave` or `flask`: the picture shown when there is no image or it fails to load), `featured` and `stats`.
2. Put a compressed image in `images/projects/` and point `image` at it (for example `images/projects/my-project.webp`), with a short `imageAlt`.

## Blog flow

blogBot commits a Markdown post to `blogs/` and prepends its filename to `blogs/blogList.json` (newest first). A post appears on the site once it is listed there. The homepage shows the post count and a live strip with the latest post, and a post gets a "Live" badge for 3 days after its date. Posts can be linked directly with `html/blogs.html#<filename>`.
